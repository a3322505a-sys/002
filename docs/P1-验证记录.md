# P1 节拍器

范围：深色中文节拍页，30–240 BPM、首次 60、加减／圆盘／数值输入，4/4、第一拍重音，持久化恢复但不自动播放。

- 布局参考 1000012181.jpg；原生 Java/View，圆盘只负责调速，不负责计时。固定拍号不做成按钮。
- 复用上游 PCM 和音色生成。改为节拍边界读取新速度，取消旧版变速后强制 200ms 重排。
- AccuracyTimer 用单调期限，回调过载时跳过已过期的期限，避免集中补拍。停止不在持锁情况下等待线程。
- 前台服务持有音频焦点，通知提供停止；失去焦点／拔耳机暂停，系统重建不自动发声。
- 无启动麦克风请求；启动只恢复速度，非法持久值回退 60。
- CI 检查构建、基础控制、播放变速与停止；截图用于视觉检查。冷启动 ≤1s、真机锁屏三分钟和音频稳定性仍需设备实测。
