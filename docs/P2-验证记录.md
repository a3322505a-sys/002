# P2 调音＋节拍

范围：完成首批二合一工具，版本 0.2.2-p2 / code 5，沿用 P0 的安装身份和私有签名。

| 需求 | 实现规则 | 验收 |
| --- | --- | --- |
| 调音琴头界面 | 原创原生矢量木色琴头、金属弦钮和六根弦线；共享坐标高亮，无实时3D或大图加载 | 1弦E4、2弦B3、3弦G3、4弦D3、5弦A2、6弦E2 按钮和弦钮对应；CI导出模拟器截图；紧凑布局完整显示六弦，麦克风入口位于顶部 |
| 偏差明确 | A4=440Hz，1200×log2(输入/所选目标)，±5音分视为调准 | 六弦、偏高/偏低、无效输入单测；不自动修正八度，过大偏差保留实值 |
| 信号真实 | 复用 Diatronome Envelop 算法，AudioRecord真实输入；三帧中值，仅在有有效输入时更新，500ms过期清除 | 无声显示拨动琴弦；真琴低E、响应与噪声仍待用户试装 |
| 切页和权限 | 进调音停节拍，离开/后台释放录音；采集串行且每次录音独立持有资源，避免P0共享对象释放竞争 | 模拟器快速切页；release拒绝麦克风后仍能开关节拍 |
| 轻量启动 | 新页面原生布局，保存速度/页面/琴弦；不恢复自动播放；仅使用调音时请求麦克风 | 模拟器五次冷启动记录；手机≤1秒目标仍待真机，不能混同平台成绩 |

P1 已授权连续进入 P2；P2 完成后停止，不实施 P3 跟拍评分。测试中的合成音仅用于验证，产品界面不显示测试数据。

参考图：1000012181.jpg、1000012183.jpg，原件已取回独立保存供设计核对。琴头由 HeadstockView.java 原创绘制，未截取参考图片的琴头作为素材。

运行代码、单元测试、模拟器和截图依据 PR 的 CI 结果验收；实际听感、六弦稳定性和锁屏三分钟由用户手机试装确认。
